# CMDB 需求规格说明书

## 1. 引言

### 1.1 目的

本文档描述运维部 CMDB（配置管理数据库）系统的功能需求和非功能需求，为系统设计、开发和测试提供依据。

### 1.2 范围

CMDB 系统是一个用于管理和追踪企业 IT 配置项的平台，支持配置项的增删改查、关系管理、变更管理和审计日志功能。

### 1.3 定义和缩略语

| 术语 | 定义 |
|------|------|
| CMDB | 配置管理数据库 (Configuration Management Database) |
| CI | 配置项 (Configuration Item) |
| RBAC | 基于角色的访问控制 (Role-Based Access Control) |
| JWT | JSON Web Token |

## 2. 用户角色

### 2.1 系统管理员 (admin)

- 拥有系统全部权限
- 管理用户和角色
- 管理所有配置项
- 审批变更申请

### 2.2 运维工程师 (operator)

- 创建和编辑配置项
- 发起变更申请
- 查看审计日志
- 无删除权限

### 2.3 只读用户 (viewer)

- 仅查看配置项
- 查看变更记录
- 无修改权限

### 2.4 审计员 (auditor)

- 查看配置项和变更记录
- 审批变更申请
- 导出审计日志

## 3. 功能需求

### 3.1 认证管理

#### 3.1.1 用户登录
- **ID**: AUTH-001
- **描述**: 用户可以通过用户名和密码登录系统
- **验收标准**:
  - 输入正确的用户名和密码可以成功登录
  - 输入错误的用户名或密码显示错误提示
  - 登录后跳转至首页

#### 3.1.2 用户注册
- **ID**: AUTH-002
- **描述**: 新用户可以通过注册功能创建账号
- **验收标准**:
  - 用户名唯一性验证
  - 邮箱格式验证
  - 密码强度验证（至少 8 位）

#### 3.1.3 登出
- **ID**: AUTH-003
- **描述**: 用户可以安全退出系统
- **验收标准**:
  - 点击登出后清除本地 Token
  - 跳转到登录页面

### 3.2 配置项管理

#### 3.2.1 配置项列表
- **ID**: CI-001
- **描述**: 用户可以查看所有配置项的列表
- **验收标准**:
  - 支持分页显示
  - 支持按类型、状态、负责人过滤
  - 显示关键字段（名称、类型、状态、负责人）

#### 3.2.2 配置项搜索
- **ID**: CI-002
- **描述**: 用户可以通过关键字搜索配置项
- **验收标准**:
  - 支持按名称模糊搜索
  - 支持多条件组合搜索
  - 搜索结果高亮显示

#### 3.2.3 创建配置项
- **ID**: CI-003
- **描述**: 用户可以创建新的配置项
- **验收标准**:
  - 表单字段完整
  - 必填字段验证
  - 创建成功后跳转到详情页

#### 3.2.4 编辑配置项
- **ID**: CI-004
- **描述**: 用户可以编辑现有配置项
- **验收标准**:
  - 回显现有数据
  - 保存后更新相关信息

#### 3.2.5 删除配置项
- **ID**: CI-005
- **描述**: 授权用户可以删除配置项
- **验收标准**:
  - 删除前需要确认
  - 仅管理员可删除

#### 3.2.6 配置项详情
- **ID**: CI-006
- **描述**: 用户可以查看配置项的详细信息
- **验收标准**:
  - 显示所有字段信息
  - 显示关联的配置项
  - 显示变更历史

### 3.3 关系管理

#### 3.3.1 创建关系
- **ID**: REL-001
- **描述**: 用户可以创建配置项之间的关系
- **验收标准**:
  - 选择目标配置项
  - 选择关系类型
  - 支持的关系类型：依赖、连接、运行于、包含、部署于

#### 3.3.2 查看关系
- **ID**: REL-002
- **描述**: 用户可以查看配置项的关系
- **验收标准**:
  - 列表显示所有关系
  - 图形化展示关系图

#### 3.3.3 删除关系
- **ID**: REL-003
- **描述**: 用户可以删除配置项关系
- **验收标准**:
  - 删除前需要确认

### 3.4 变更管理

#### 3.4.1 发起变更
- **ID**: CHG-001
- **描述**: 用户可以发起变更申请
- **验收标准**:
  - 填写变更描述和原因
  - 设置优先级和计划时间

#### 3.4.2 审批变更
- **ID**: CHG-002
- **描述**: 授权用户可以审批变更申请
- **验收标准**:
  - 审批人可以批准或拒绝
  - 填写审批意见

#### 3.4.3 变更记录
- **ID**: CHG-003
- **描述**: 系统记录所有变更历史
- **验收标准**:
  - 记录变更前后对比
  - 记录变更时间和操作人

### 3.5 审计日志

#### 3.5.1 日志记录
- **ID**: AUD-001
- **描述**: 系统自动记录用户操作
- **验收标准**:
  - 记录登录/登出操作
  - 记录资源增删改操作
  - 记录操作时间和 IP

#### 3.5.2 日志查询
- **ID**: AUD-002
- **描述**: 用户可以查询审计日志
- **验收标准**:
  - 按时间范围查询
  - 按用户查询
  - 按操作类型查询

#### 3.5.3 日志导出
- **ID**: AUD-003
- **描述**: 授权用户可以导出审计日志
- **验收标准**:
  - 支持 CSV 格式导出
  - 支持 Excel 格式导出

## 4. 非功能需求

### 4.1 性能需求
- 页面加载时间 < 3 秒
- API 响应时间 < 500ms
- 支持并发用户数 ≥ 100

### 4.2 安全需求
- 密码加密存储（bcrypt）
- JWT Token 认证
- HTTPS 传输加密
- SQL 注入防护
- XSS 防护

### 4.3 可用性需求
- 系统可用性 ≥ 99.9%
- 支持数据备份和恢复
- 支持高可用部署

### 4.4 兼容性需求
- 支持 Chrome、Firefox、Safari、Edge 浏览器
- 支持响应式布局

## 5. 数据模型

### 5.1 配置项类型

| 类型 | 代码 | 描述 |
|------|------|------|
| 服务器 | server | 物理服务器、虚拟机 |
| 网络设备 | network_device | 路由器、交换机、防火墙 |
| 数据库 | database | MySQL、PostgreSQL、MongoDB |
| 中间件 | middleware | Redis、Kafka、Nginx |
| 应用 | application | Web 应用、API 服务 |
| 容器 | container | Docker 容器 |
| K8s 资源 | k8s_resource | Pod、Deployment、Service |
| 云资源 | cloud_resource | ECS、RDS、SLB |

### 5.2 配置项状态

| 状态 | 代码 | 描述 |
|------|------|------|
| 在线 | online | 正常运行中 |
| 离线 | offline | 已停机 |
| 维护中 | maintenance | 维护状态 |
| 故障 | error | 故障状态 |
| 已退役 | retired | 已退役 |

## 6. 用户故事

### 6.1 作为系统管理员
- 我希望创建和管理用户账号，以便控制系统访问
- 我希望分配角色权限，以便实现权限隔离
- 我希望查看所有操作日志，以便进行安全审计

### 6.2 作为运维工程师
- 我希望快速创建配置项，以便及时更新资源信息
- 我希望查看配置项关系，以便理解系统依赖
- 我希望发起变更申请，以便进行系统变更

### 6.3 作为只读用户
- 我希望搜索配置项，以便查找所需信息
- 我希望导出配置项列表，以便生成报告

### 6.4 作为审计员
- 我希望查看变更记录，以便追踪配置变化
- 我希望导出审计日志，以便生成合规报告

## 7. 验收标准

### 7.1 功能验收
- 所有用户故事已实现
- 所有功能需求已通过测试

### 7.2 性能验收
- 性能测试通过，满足响应时间要求
- 负载测试通过，满足并发用户要求

### 7.3 安全验收
- 安全扫描无高危漏洞
- 渗透测试通过
