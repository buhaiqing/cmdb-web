# CMDB 系统架构设计文档

## 1. 系统概述

CMDB（配置管理数据库）是一个统一的 IT 资源配置管理平台，用于管理和追踪企业内的所有配置项（CI）及其关系。

### 1.1 技术栈

| 层级 | 技术选型 | 版本 |
|------|----------|------|
| 前端框架 | Vue 3 + TypeScript | 3.4 |
| 构建工具 | Vite | 5.0 |
| 状态管理 | Pinia | 2.1 |
| UI 组件库 | Element Plus | 2.5 |
| 路由 | Vue Router | 4.2 |
| HTTP 客户端 | Axios | 1.6 |
| E2E 测试 | Playwright | 1.41 |
| 后端框架 | FastAPI | 0.109 |
| ORM | SQLAlchemy | 2.0 |
| 数据库 | PostgreSQL | 15 |
| 缓存 | Redis | 7 |
| 认证 | JWT (python-jose) | - |
| 密码加密 | bcrypt (passlib) | - |
| 数据库迁移 | Alembic | - |

## 3. 核心模块设计

### 3.1 认证授权模块

采用 JWT Token 认证机制：

```
┌──────────┐     登录请求      ┌──────────┐
│  Client  │ ────────────────> │   Auth   │
│          │                   │ Service  │
│          │ <──────────────── │          │
│          │    JWT Token      │          │
└──────────┘                   └──────────┘
     │                              │
     │  携带 Token 请求              │
     ├────────────────────────────> │
     │                              │ 验证 Token
     │                              ├──────────┐
     │                              │          │
     │                              │<─────────┤
     │                              │
     │  返回受保护资源               │
     │ <─────────────────────────── │
```

### 3.2 配置项多态设计

支持 8 种配置项类型，采用主表 + 子表设计：

```
t_configuration_item (主表)
├── id
├── ci_type (枚举)
├── name
├── status
└── ...

t_ci_server (子表)          t_ci_database (子表)
├── id                      ├── id
├── ci_id (FK)              ├── ci_id (FK)
├── hostname                ├── db_type
├── ip_address              ├── version
├── os_type                 ├── host
└── ...                     └── ...
```

## 5. 安全设计

### 5.1 认证安全
- JWT Token 认证，支持 Token 刷新
- 密码使用 bcrypt 加密存储
- Token 过期时间可配置

### 5.2 授权安全
- 基于角色的访问控制（RBAC）
- API 级别的权限校验
- 操作审计日志记录

### 5.3 数据安全
- SQL 注入防护（参数化查询）
- XSS 防护（输入验证）
- CSRF 防护（Token 验证）
